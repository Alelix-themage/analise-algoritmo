# 2) Problema das K-Partições
Crie um programa que, dado um vetor de inteiros positivos V de tamanho
variável, encontre os diferentes subconjuntos disjuntos que tenham o
mesmo valor resultante da soma de seus elementos, de forma que todos
os elementos de V sejam cobertos. Imprima os resultados na tela.
Exemplo:
V = { 7, 3, 5, 12, 2, 1, 5, 3, 8, 4, 6, 4 }
V pode ser particionado em 2. Cada subconjunto tem soma = 30
S1 = { 5, 3, 8, 4, 6, 4 }
S2 = { 7, 3, 5, 12, 2, 1 }
V pode ser particionado em 3. Cada subconjunto tem soma = 20
S1 = { 2, 1, 3, 4, 6, 4 }
S2 = { 7, 5, 8 }
S3 = { 3, 5, 12 }
V pode ser particionado em 4. Cada subconjunto tem soma = 15
S1 = { 1, 4, 6, 4 }
S2 = { 2, 5, 8 }
S3 = { 12, 3 }
S4 = { 7, 3, 5 }
V pode ser particionado em 5. Cada subconjunto tem soma = 12
S1 = { 2, 6, 4 }
S2 = { 8, 4 }
S3 = { 3, 1, 5, 3 }
S4 = { 12 }
S5 = { 7, 5 }
